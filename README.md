# Filmthing

Приложение для поиска фильмов через открытое API. Учебный проект на Kotlin + Jetpack Compose с соблюдением современных стандартов разработки.

## Статус

MVP в разработке. На данный момент завершена настройка проекта.

## Стек

- **Язык:** Kotlin 2.2.10
- **UI:** Jetpack Compose + Material 3
- **Архитектура:** Clean Architecture + MVVM + MVI (планируется)
- **DI:** Koin (планируется)
- **Сеть:** Retrofit + OkHttp (планируется)
- **БД:** Room (планируется)
- **Изображения:** Coil (планируется)

## Архитектура

Проект использует Package-by-Feature внутри одного модуля с разделением на слои `domain`, `data`, `presentation` внутри каждой фичи. Цель — высокая связность (High Cohesion) и слабая связанность (Low Coupling) для потенциального перехода к модульной архитектуре.

## Качество кода

- **ktlint** — форматирование
- **detekt** — статический анализ
- **Android Lint** — проверки платформы

Все три линтера настроены с `maxIssues: 0` и проходят на текущей кодовой базе.
